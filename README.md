# First-Person Arena Shooter Prototype

This project is a fast-paced first-person arena shooter prototype developed as the final project for **GAM207**.  
The goal of this project was to design and implement core gameplay systems commonly found in FPS games, with a focus on player movement, combat, AI behavior, and UI feedback.

## Project Overview

- Engine: Unreal Engine 5
- Genre: First-Person Shooter
- Scope: Solo course project
- Focus Areas: Gameplay systems, AI behavior, combat mechanics, and UI integration

This prototype emphasizes moment-to-moment gameplay through responsive controls, enemy interaction, and clear player feedback systems.

---

## Implemented Systems & Features

### Player Systems
- WASD movement with sprinting, crouching, jumping, and hip-fire shooting
- Health and armor system with damage handling
- Respawn system for continuous gameplay flow

### Combat & AI
- AI enemy with wandering, target tracking, and attack behaviors
- Enemy health and armor logic with UI feedback
- Damage interaction between player and AI entities

### UI & Feedback
- Health and armor HUD for the player
- Enemy health and armor widgets
- Score tracking system with a scoreboard interface
- Visual feedback for pickups and combat interactions

### Level & Assets
- Blockout-style arena level designed for fast-paced combat
- All assets created directly within Unreal Engine using built-in modeling tools
